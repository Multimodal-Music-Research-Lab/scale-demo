SCALE

Structural Context from Audio and Lyric Evidence for Music Structure Analysis.

SCALE detects musical section boundaries and assigns section labels such as verse, chorus, bridge, and instrumental. This page lets you listen to selected HX test songs while comparing the model output with the reference structure on a shared timeline.

    How to read the demo

    One song, two aligned views

    Reference shows the HX test annotation. SCALE shows the model prediction from the released inference pipeline.

    Pre-chorus is mapped to verse, matching the evaluation protocol. The colored blocks retain every predicted boundary, including adjacent sections with the same label.

    Audio is played from the dataset’s YouTube source. The demo does not redistribute the underlying copyrighted recordings.
