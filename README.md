# SCALE Demo

Interactive companion demo for **SCALE: Structural Context from Audio and Lyric Evidence for Music Structure Analysis**.

The page presents ten songs from SongFormBench-HX, the 200-song HarmonixSet subset of [SongFormBench](https://huggingface.co/datasets/ASLP-lab/SongFormBench). For each song, visitors can stream the corresponding SongFormBench WAV and compare the HX ground-truth annotation with the SCALE prediction on the same timeline.

## Live demo

<https://multimodal-music-research-lab.github.io/scale-demo/>

## Notes

- Pre-chorus is mapped to verse, following the evaluation protocol.
- Audio is streamed directly from the WAV files published with SongFormBench. The dataset card specifies the [Creative Commons Attribution 4.0 International license](https://creativecommons.org/licenses/by/4.0/). Audio files are not copied into this repository.
