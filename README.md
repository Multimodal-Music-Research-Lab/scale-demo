# SCALE Demo

Interactive companion demo for **SCALE: Structural Context from Audio and Lyric Evidence for Music Structure Analysis**.

The page presents ten curated songs from the 200-song SongFormBench-HX test set. For each song, visitors can stream the corresponding SongFormBench WAV and compare the HX reference annotation with the SCALE prediction on the same timeline.

## Live demo

<https://multimodal-music-research-lab.github.io/scale-demo/>

## Notes

- SongFormer results were used only to select examples where SCALE performs better; they are not displayed on the page.
- Pre-chorus is mapped to verse, following the evaluation protocol.
- Audio is streamed directly from the WAV files published with [SongFormBench](https://huggingface.co/datasets/ASLP-lab/SongFormBench) under [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). Audio files are not copied into this repository.
