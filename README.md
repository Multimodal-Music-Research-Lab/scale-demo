# SCALE Demo

Interactive companion demo for **SCALE: Structural Context from Audio and Lyric Evidence for Music Structure Analysis**.

The page presents ten curated songs from the 200-song SongFormBench-HX test set. For each song, visitors can listen through the original YouTube source and compare the HX reference annotation with the SCALE prediction on an aligned timeline.

## Live demo

<https://multimodal-music-research-lab.github.io/scale-demo/>

## Notes

- SongFormer results were used only to select examples where SCALE performs better; they are not displayed on the page.
- Pre-chorus is mapped to verse, following the evaluation protocol.
- The repository does not redistribute copyrighted audio. Playback uses the source YouTube links.
